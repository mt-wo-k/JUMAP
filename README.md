# JUMAP

都道府県を選び、市区町村と政令指定都市の行政区に数値を入力して色分けする、個人利用向けのWebアプリです。

## 開発

`npm install` の後に `npm run dev` でフロントエンドの開発サーバーを起動します。自動テストは `npm test` で実行します。

GitHub に push して Vercel のプロジェクトに接続すると、フロントエンドと同期APIがデプロイされます。

## 使い方

1. マップ名、対象都道府県、単位、最大値の色を指定してマップを作成します。
2. 地図上の市区町村・行政区を選択し、数値とメモを保存します。
3. 入力済みの数値の最小値は地図背景色、最大値は設定色になり、その間はRGBで補間します。
4. 値が未入力の地域は背景色で表示します。入力がすべて同じ値の場合は最大値の色で表示します。

マップと入力内容はブラウザーの localStorage に保存します。同期設定後は、Vercel Function 経由で Upstash Redis にも保存し、別端末と共有します。通信に失敗した変更を後から自動再送する機能はありません。

## 端末間同期の設定

同期を使わない場合は設定不要です。初回だけ、地図データが入っている端末で次の設定を行い、その後ほかの端末にも同じ同期キーを設定してください。

1. [Upstash](https://upstash.com/) で Redis データベースを作成します。個人利用なら Free プランを選べます。
2. Vercel の Upstash for Redis 連携を Production に接続すると、`KV_REST_API_URL` と `KV_REST_API_TOKEN` が自動で追加されます。値はサーバー側だけで使い、`VITE_` 接頭辞は付けません。
3. 同期機能を含むJUMAPをデプロイし、同期設定を開いて「安全なキーを生成」し、そのキーをコピーします。
4. 同じ値を Vercel の Environment Variables に `JUMAP_SYNC_KEY` として登録し、再デプロイします。Production を使う場合は Production に登録してください。Preview でも試す場合は Preview にも同じキーを設定します。
5. データのある最初の端末で同期設定画面にキーを保存します。クラウドに初期データを登録します。次に iPhone など別端末で同じキーを保存すると、クラウド上のマップが読み込まれます。

同期キーは端末ごとのブラウザーに保存します。忘れた場合は、同じキーを Vercel の環境変数と各端末に再設定してください。キー解除はその端末の接続だけを解除し、クラウド上のデータは削除しません。認証アカウントはありません。同期キーを知る人はデータの読み書きができるため、第三者に共有しないでください。

Vite の `npm run dev` はフロントエンドのみを起動します。同期 Function も含むローカル動作を確認する場合は Vercel CLI の `vercel dev` を使用し、必要な環境変数を設定してください。変数名一覧は `.env.example` を参照してください。

## 境界データ

`public/data/municipalities/<都道府県コード>/municipalities.topojson` に、選択された都道府県のTopoJSONを置いています。地図を開く際に選択地域だけ取得し、ブラウザー上でGeoJSONに変換します。

元データは [kyodo-official/japan-choropleth](https://github.com/kyodo-official/japan-choropleth) の都道府県別市区町村TopoJSONです。共同通信社が国土交通省 国土数値情報「行政区域データ」2025年版を加工したデータを使用しています。行政区域データは CC BY 4.0 で提供されており、このアプリでは出典を画面内と本READMEに表示しています。境界データは共同通信社のコードと別ライセンスです。

地図表示では、北海道の礼文・利尻・奥尻、東京都の伊豆・小笠原、新潟県の佐渡・粟島、山形県の飛島、島根県の隠岐、長崎県の壱岐・対馬・五島、鹿児島県の種子島・屋久島・三島・十島・奄美を省略します。東京都の「所属未定地」に含まれる遠隔島の境界断片と酒田市の飛島部分も対象です。沖縄県と沿岸・瀬戸内の島は表示します。省略した地域の入力値やメモは保存データから削除されません。

- 出典: 共同通信社「japan-choropleth」

## 技術構成

- React 19 + TypeScript + Vite
- React Leaflet / Leaflet（背景タイルなし、ポリゴンのみ）
- TopoJSON（選択都道府県ごとに遅延取得）
- localStorage（端末内保存と共有同期キー）
- Vercel Function + Upstash Redis（共有スナップショットの保存）

## 同期データの扱い

同期はマップ一覧全体を1つのクラウドスナップショットとして保存します。初回の端末はクラウドが空の場合にだけローカルデータを登録し、クラウドにデータがある場合はクラウド側を読み込みます。同期後の編集・削除は700ミリ秒程度まとめて保存します。
